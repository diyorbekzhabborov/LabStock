# LabStock — Windows-система управления запасами частной медицинской лаборатории

**Версия:** 1.0 (MVP)  
**Платформа:** .NET 8 WPF (C#)  
**База данных:** SQLite (Entity Framework Core) — 100% автономная локальная работа без интернета  
**Отчёты и экспорт:** ClosedXML (Excel `.xlsx`), QuestPDF (PDF `.pdf`), CSV (UTF-8)

---

## 🎯 Соответствие Техническому Заданию (ТЗ)

Приложение **LabStock** полностью разработано в строгом соответствии с представленным ТЗ:

1. **Ключевая бизнес-логика:**
   $$\text{Анализ} \longrightarrow \text{Норма расхода} \longrightarrow \text{Количество анализов} \longrightarrow \text{Автоматическое FEFO-списание} \longrightarrow \text{Новый остаток} \longrightarrow \text{Журнал движений} \longrightarrow \text{Отчёты}$$
2. **Защита от отрицательных остатков:**
   - По умолчанию отрицательный остаток строго запрещен. При попытке списания нехватки система выводит предупреждение с детальным перечнем дефицитных позиций.
3. **Алгоритм FEFO (First Expired, First Out):**
   - Автоматический учет партий и списание в первую очередь с партий с ближайшим сроком годности.
4. **Сквозной журнал движений:**
   - Прямое ручное редактирование остатков исключено — все изменения проводятся через документы поступления, списания по анализам, ручные акты или акты инвентаризации.
5. **Роли и безопасность:**
   - Ролевой доступ (RBAC): Администратор, Заведующий лабораторией, Лаборант, Только просмотр.
   - Хеширование паролей (SHA-256) и журнал аудита действий.
6. **Резервное копирование и восстановление:**
   - Горячий снапшот базы данных SQLite с проверкой целостности (`PRAGMA integrity_check`) и защитным сохранением перед восстановлением.

## 🚀 Быстрый запуск

Запустить приложение можно любым из способов:
- Двойным кликом по файлу: **`Запуск_LabStock.bat`** в корне папки.
- Либо запустить исполняемый файл: `LabStock\bin\Release\net8.0-windows\win-x64\publish\LabStock.exe`.
- Для сборки из исходного кода в терминале:
  ```bash
  cd "d:\Новая папка\LabStock"
  dotnet run
  ```

## 📋 Разделы программы

1. **Главная / Dashboard**:
   - 6 ключевых индикаторов: Всего позиций, Общий остаток, Низкий остаток, Истекает срок, Использовано сегодня, Анализов сегодня.
   - Панель быстрых действий («⚡ Выполнить анализ», «📥 Поступление», «📤 Списание», «📊 Отчёт за сегодня»).
   - Таблица критических позиций и дефицита с бейджами.
   - График динамики расхода за 7 дней.
   - Лента последних складских операций.

2. **Склад и остатки**:
   - Таблица материалов со статусами (*Норма, Внимание, Низкий остаток, Нет на складе*).
   - Фильтры по категориям, статусам, поиск по названию, коду, штрихкоду, стеллажу.
   - Панель детализации партий выбранного материала (номер партии, текущий остаток, дата поступления, срок годности, дни до истечения, цена закупки в сомони).

3. **Справочник материалов и реагентов**:
   - Создание и редактирование расходных позиций (название, категория, единица измерения, артикул, штрихкод/QR, пороги минимума/максимума, поставщик, место хранения, начальный остаток).

4. **Поступления (Приход)**:
   - Оформление накладной поставщика с несколькими товарными позициями, номерами партий, сроками годности и закупочными ценами.
   - Автоматическое увеличение остатка и создание партий.

5. **Ручные списания**:
   - Оформление списания по причинам: *Повреждение, Брак упаковки, Истечение срока годности, Потеря, Контроль качества (QC), Внутреннее использование, Другое*.
   - Выбор конкретной партии или автоматическое списание по FEFO.

6. **Справочник анализов и нормы расхода**:
   - Справочник исследований (ОАК, Глюкоза, Холестерин, Тропонин и др.).
   - Конструктор рецептов: задание точных норм расхода материалов на 1 выполненный анализ.

7. **Выполнение анализа (Списание расходников)**:
   - Выбор анализа и указание количества (с быстрыми кнопками `+5`, `+10`, `+25`, `+50`).
   - Таблица предварительного расчёта расхода материалов с проверкой складского наличия.
   - Подтверждение списания по FEFO в 2 клика.

8. **Движение склада**:
   - Полный хронологический журнал всех операций.
   - Фильтры по датам, операциям, поисковой строке.
   - Кнопки экспорта в **Excel (.xlsx)** и **CSV**.

9. **Центр оповещений**:
   - Автоматический мониторинг низкого остатка, критического остатка, истечения сроков годности и просроченных реагентов.

10. **Отчёты и аналитика**:
    - **Ежедневный отчёт**: статистика выполненных анализов, остатки на начало дня, приход, расход по анализам, ручные списания, конечные остатки. Экспорт в **PDF** и **Excel**.
    - **Ежемесячный отчёт**: финансовая оценка склада в сомони, сумма закупок, расход по категориям, топ расходуемых позиций, подневная динамика. Экспорт в **Excel**.
    - **Аналитика и прогнозы**: расчёт среднесуточного/месячного расхода, дней до полного исчерпания (Runway), рекомендуемый объём дозаказа.

11. **Поставщики**:
    - Контрагенты, контактные лица, телефоны, адреса.

12. **Инвентаризация**:
    - Ввод фактического количества, авторасчёт разницы, обязательное указание причины и создание корректирующей операции.

13. **Журнал аудита**:
    - Фиксация входов/выходов, создания документов, изменений справочников и резервных копий.

14. **Пользователи**:
    - Управление учётными записями, смена ролей и статусов активности.

15. **Настройки и Резервное копирование**:
    - Название лаборатории, валюта (сомони), порог срока годности (7, 15, 30, 60 дней), переключатель отрицательных остатков.
    - Мгновенное создание резервной копии базы данных `.db` и восстановление из файла с защитой.
